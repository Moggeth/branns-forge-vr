# Timberline twin-bolt ballista (asset kit, 2026-10-03)

A handmade hardwood, iron, brass and mithril ballista. It fires two mirrored bolts joined by a cutting filament. The sequence is release, then vanes flick open, then the pair spreads, then the filament snaps taut.

- Open `preview/index.html` through any static server rooted at this folder. It loads three.js from jsdelivr.
- Review renders are in `renders/`.
- Integration notes, the API, budgets and limitations are in **[HANDOFF.md](HANDOFF.md)**.

The kit is not installed in the game yet.
