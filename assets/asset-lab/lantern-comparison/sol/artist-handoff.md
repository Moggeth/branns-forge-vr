# Cinderleaf lantern — GPT-6 Sol comparison build

> Archived artist handoff. The `work/lantern-comparison/sol` paths below refer
> to the isolated commission. The maintained builder, source, spec, and preview
> files now live beside this handoff; the installed GLB is
> `godot/assets/forge_lantern/sol.glb`. See the parent comparison README for
> current build and verification commands.

Independent low-poly hand lantern for Brann's Forge VR. Oxidized copper rain cowl, golden edges, a warm opal chamber, a fixed leather-wrapped bail, and an outward-opening louvred front shutter. The 80 mm grip section is 26 mm in diameter. Geometry and albedo are generated by `build.py`; no third-party image or mesh is used.

Build with bundled Blender 4.5.13:

```powershell
& tools/blender-4.5.13-windows-x64/blender.exe --background --factory-startup --python-exit-code 2 --python work/lantern-comparison/sol/build.py -- --out C:/Users/mog/OneDrive/Documents/Coding/Personal/Python/things_are_different_now/branns-forge-vr/work/lantern-comparison/sol
```

Deliverables: `model.glb` (embedded patina albedo), editable `source.blend`, `front.png`, `three_quarter.png`, `open.png`; `asset.json` describes the inspection contract. The source scene has a `Shutter open outward` animation: frame 1 closed, frame 20 open 105 degrees. `ShutterHinge` owns all moving shutter meshes and rotates around Godot +Y. `ShutterThumb` is on its free edge. `Grip` and `Flame` are empty interaction markers. Gameplay collision, light, and grip behavior are for the game adapter; this package supplies art and pivots.

Asset Lab inspection command:

```powershell
python scripts/asset_lab.py inspect work/lantern-comparison/sol/asset.json work/lantern-comparison/sol/model.glb --out work/lantern-comparison/sol/validation
```

`validation/report.json` passed: 119,752 bytes, 1,340 triangles, 50 meshes, 6 materials, 1 embedded image, 1 animation; Khronos validator 0 errors and 0 warnings. Disposable Godot import retained all required nodes and measured 0.131 × 0.323 × 0.147 m, within the 0.25 × 0.45 × 0.25 m envelope. Visual review of `front.png` and `open.png` confirmed the shutter opens away from the glass without visible clipping.

Measured local steps (wall seconds): contract/pilot inspection 0.6; initial Blender build 1.806; first render review 0.2; corrected Blender build 2.226; Asset Lab inspection 2.529. The first build placed hinge barrels away from the pivot and the open preview remained closed because animation evaluation restored frame 1. Parenting the barrels with a preserved world transform and rendering frame 20 resolved both. For future pose review, select the animation frame rather than assigning a keyed transform directly.
