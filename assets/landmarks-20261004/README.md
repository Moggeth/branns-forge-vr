# Landmark kits

`build_sanctuary.py` builds the Ancient Stone Sanctuary kit (menhirs, trilithon, altar, hoop, chains, moss, rubble)
with procedural textures and writes `sanctuary_kit.glb` here.

    pip install bpy==4.5.*
    python3 build_sanctuary.py
    cp sanctuary_kit.glb ../../multiplayer/public/assets/

Textures and the local .glb are regenerated by the script and are not committed; the shipped copy is
`multiplayer/public/assets/sanctuary_kit.glb`. `client/starting-world.js` swaps it in for the code-built stones once it
loads (`installKit`); `tests/sanctuary-kit.mjs` checks the piece names, materials and rune anchors it relies on.
