# Gloamfen authored environment

The previous Gloamfen was a low-contrast plane with scattered mushroom stems and separated boardwalk slabs. Sonnet 5.5 produced the reusable wetland kit in [`assets/gloamfen-sonnet/`](../assets/gloamfen-sonnet/HANDOFF.md): fen trees, stone/mud banks, ruins, pale stepping stones, connected boardwalk modules, warm lanterns, fungi and the tall arch-tree beyond the back gate. The actual game's [ground view](../assets/gloamfen-sonnet/previews/game_ground.png) and [RTS view](../assets/gloamfen-sonnet/previews/game_rts.png) can be compared with [before ground](../assets/gloamfen-sonnet/previews/before_ground.png) and [before RTS](../assets/gloamfen-sonnet/previews/before_rts.png). Studio renders are in the same previews folder, but the game captures are the approval reference.

The commission ran on the verified personal Claude.ai Pro subscription as `claude-sonnet-5-5` in an isolated work folder, taking 741.455 seconds. Codex copied the self-contained GLBs and full placement manifest into `godot/assets/zone_art/gloamfen/` and imported all 29 assets into Godot. `WorldZones.build()` uses the general zone-art adapter, which batches the 210 placements into 78 mesh holders and creates 46 simple, explicitly authored collision shapes. The art itself never replaces the level's floor, quest resources, enemies or portals. The old redundant mushroom/tree/arch dressing is retired only while the manifest exists. Five spore pickups and three wisps remain; a spore patch was shifted off the centre of the walkway. Seventeen slab/link colliders retain an uninterrupted walking surface under the new boards.

The kit has 13,458 unique triangles and roughly 69,000 placed triangles before culling. In an actual desktop mono capture on the RTX 3080 Ti, Gloamfen reported 120 FPS (the game's cap), 247 visible objects and 235 draw calls. This is a composition and desktop performance check, not proof of headset stereo frame time. The overall palette was given a little more directional light and slightly less ambient fill to separate bark, stone and plank faces while retaining the dim fairy-friendly mood.

Verification: editor import completed in 6.074 seconds; the focused Gloamfen check reported zero failures in 2.620 seconds, preserving all resources/enemies, boardwalk collision and a standing-capsule route from the entrance past the back gate; all 22 portal capsule/ray checks passed in 2.629 seconds; the full disposable-fixture integration passed in 55.581 seconds. The native Gloamfen capture completed in 11.077 seconds; the 24-view environmental review had no failures and took about 11 seconds wall time. Exact VR comfort and stereo performance still need a headset pass.

The first focused test counted the zone's base floor along with 17 boardwalk bodies and looked for `kind=wisp`, while enemies actually store `enemy_type=wisp`. Once corrected, it found a centre-path collision at z=-15: an intended wisp combatant, not static environment. The environmental sweep now excludes living enemy collision RIDs and continues to catch art/architecture blockers. Also, the Claude runner keeps its JSONL open for writing; `ReadAllLines()` without file sharing raised a file-in-use error during progress inspection. Prefer file size/mtime, or open a read stream with `FileShare.ReadWrite` when a live inspection is necessary.

To rebuild safely, copy the builder to an isolated output folder, run Blender there, review its new GLBs and manifest, then copy them into the installed kit and run Godot's editor import. The builder writes beside itself, including `HANDOFF.md`; running it directly inside the curated source directory would overwrite the integrated notes and game captures.
