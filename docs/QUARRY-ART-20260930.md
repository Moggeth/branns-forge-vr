# Sandstone Quarry authored art — 2026-09-30

Sonnet 5.5 made the warm sandstone kit; Codex integrated it into the existing zone without moving ore, the golem, the bomb barrier, the crystal, or the shared floor. The prior generic cube wall and scattered boulder perimeter is a fallback only when the authored manifest is absent. The installed kit adds layered chisel-scored strata, rim cliffs, timber scaffold cranes, cut slabs, route lanterns, an entrance gateway and a mine mouth. It is deliberately a quarry yard with room to fight and mine rather than a dense obstacle course.

Actual-game comparisons: [before, ground](../assets/sandstone-quarry-sonnet/previews/before_ground.png), [after, ground](../assets/sandstone-quarry-sonnet/previews/game_ground.png), [before, RTS](../assets/sandstone-quarry-sonnet/previews/before_rts.png), [after, RTS](../assets/sandstone-quarry-sonnet/previews/game_rts.png). Sonnet's Blender reference renders are in the same `previews/` directory but are not substitutes for the game captures.

The kit has 8 self-contained GLBs, 56 placements, 5,428 unique triangles and 33,764 placed triangles. The Godot adapter uses 80 MultiMesh holders and 58 authored simple collision shapes. The focused route check passed all 13 protected sites, including ore, golem, barrier and crystal; resource counts stayed at 3 iron, 3 stone, 1 crystal and 1 barrier. Texture and outward-winding validation passed. Real headset navigation and stereo performance remain to be checked.

Under the same 1200 × 750 whole-world capture setup, the old Quarry took **395 ground-eye draws / 440 elevated draws**. The first unbatched art export took **1,433 / 1,625**. Joining rigid pieces by material in Blender reduced the installed kit to **590 / 667**, with practically identical captures. These are comparative draw-call samples from a review viewport, not HMD GPU timings.

Source: `assets/sandstone-quarry-sonnet/build_quarry.py`, editable `quarry.blend`, `collision_intent.json`, artist `HANDOFF.md` and `stats.json`. Runtime GLBs and placement manifest: `godot/assets/zone_art/sandstone_quarry/`. Rebuild from the repository root using the pinned `tools/blender-4.5.13-windows-x64/blender.exe -b -P assets/sandstone-quarry-sonnet/build_quarry.py`, copy its GLBs and `placement_sandstone_quarry.json` into that runtime folder (rename the latter to `placement.json`), then run `scripts/Verify-ZoneArt.ps1 -Zones sandstone_quarry -Render`. Generated GLBs in the source directory are temporary; the installed runtime copies are the committed versions. The verifier records logs under ignored `logs/` and captures under ignored `outputs/environment-art-review/`.

Limitations: the floor remains the original broad sand plane, and the perimeter strata repeats a single wall family. The next art pass should add ground material breakup and another compatible wall variant before adding more small props. Preserve the mining/fight clearances and compare both camera heights.
