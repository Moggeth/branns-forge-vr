# Desktop Hero and guardian checks

From the project root, run `pwsh -File scripts/check-desktop-hero.ps1`. The runner uses the bundled Godot 4.7.2 console executable and starts five separate headless processes with `--xr-mode off` and Dummy audio. It checks mouse look and cursor ownership, isolated weapon input routing, actual Hero primary/alternate callbacks, live-scene guardian shield behavior, then an expedition world smoke check. It does not start or stop the user's running game, service, or SteamVR session.

Each check stops on failure. The console prints the failing check and its log path; inspect `logs/desktop-hero-*.log` for Godot output. The runner rejects nonzero exit codes, missing success markers, script errors, and failed assertions. It caps each engine run at 90 seconds and kills only that check process if it hangs. Per-check wall-clock seconds are appended to `logs/work-timing.csv`.

For a failure, fix the reported check or source module, then rerun this command. `--headless` checks input and scene behavior but cannot establish visual quality or headset comfort. The Hero integration check now fires Siegebird with left-click, reloads it in mouse/keyboard mode, checks visible melee swing and axe pose, and exercises weapon bob. `node scripts/check-siege-ledger.cjs` uses the isolated fixture on port 8788 to verify automatic first load, manual R reload, two actual shots and finite persistent ammunition. It never uses the live save. The existing `docs/VERIFICATION.md` documents broader verification and known fast paths.

For an actual desktop frame, run Godot without `--headless` using `--xr-mode off --path godot -- --desktop-hero-preview=axe --preview-output=<absolute PNG path>` (or `crossbow`). Add `--preview-help` to inspect the F1 sheet and `--preview-fullscreen-check` to toggle real window fullscreen and restore it before capture. The preview is offline, quits after saving, and does not change the running game. Screenshots reviewed for this pass: `outputs/desktop-hero-axe-review.png`, `outputs/desktop-hero-crossbow-review.png`, and `outputs/desktop-hero-help-review.png`.

Harness setup lesson: the first runner revision used inconsistent case names, so its guardian and expedition logs did not match the guide's `desktop-hero-*.log` glob. The runner now prefixes every log and timing row consistently. If a prior log appears absent, check the printed absolute path and rerun the current script.
