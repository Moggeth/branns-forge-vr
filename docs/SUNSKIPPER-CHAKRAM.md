# Sunskipper: the returning chakram

The existing Sunskipper has a shared, ornamented metallic GLB and new controllable
flight. This preserves Bellworks, Bankshot Bell, Lantern Parade and their rewards.

## Play

Find Sunskipper at its Bellworks or Bankshot stand (Toolbelt > Travel). In VR,
grip to take it, physically throw and release. Keep the ring flat for a gentle
glide; bank its plane left or right for a curve. Press the throwing hand's trigger
in flight to recall. The ring retains its outward momentum, slows and turns toward
that hand. Keep that hand empty to catch. Trigger while held changes throw power.

On desktop, E takes/throws, Q/R banks while held, left click changes held power or
recalls. Buttons explicitly targeted by the aiming ray retain input priority.

Scenery reflects velocity across the surface normal with 84% speed retention;
banks soften after impact. Scoring targets count once per flight. Return flight
also collides with scenery. Auto recall begins after seven seconds; twelve seconds,
a missing/occupied caller or a deep fall safely returns it to its stand. It remains
a fairground tool; this pass does not add an enemy damage system.

## Tune and extend

`godot/chakram_flight.gd` contains engine-independent glide, bank, ricochet and
bounded-acceleration recall math. `playful_tools.gd` owns collision and hand state.
Existing live tuning has `playful.ring_curve`, `ring_drag`, `ring_recall_accel` and
`ring_bounce`, alongside existing toss gain, gravity and recall speed. The schema,
native defaults and service all agree. Restart the normal game/service through its
usual launcher to pick up new source/schema; no resident VR session was interrupted.

The ring model is generated by `scripts/build-chakram.py` using bundled Blender:
`tools/blender-4.5.13-windows-x64/blender.exe --background --python scripts/build-chakram.py`.
It exports identical native/web GLBs: 5 material batches, 22,472 triangles, about
712 KB. Raised feathers, recessed bronze, enamel inlays and brushed-metal roughness
are real shared geometry/materials. This is an intentionally more detailed hero item.

## Phone showcase

Live link created this session:
https://shift-anyway-originally-hawaii.trycloudflare.com

Open on a WebGL-capable phone. Drag/pinch to inspect; Face, Edge and Reverse provide
useful angles. Try a throw exposes bank, throw, elastic recall and reset controls.
This is a lightweight playground using the same model and flight equations, with a
simple demonstration arena, not the full game or a live connection to its saves.

The link is TEMPORARY: this PC must stay awake and the two helpers must remain
running. `Share Sunskipper.cmd` starts them or prints the existing live URL.
`Stop Sunskipper Showcase.cmd` stops only the recorded helper identities. A new
start normally creates a different link. No recurring hosting subscription or
account was configured. The local page is http://127.0.0.1:8846.

The localhost server exposes only `outputs/chakram`; the forge API and player
state are outside that root. Cloudflared provides the public HTTPS tunnel.
Dependencies: Node, local `outputs/chakram/node_modules/three` (npm ci in that
folder restores it), and `tools/cloudflared.exe`. Logs live at
`logs/chakram-server*.log` and `logs/chakram-tunnel*.log`; process identities are in
`work/chakram/showcase-processes.json`. If startup finds stale state, use the stop
script before retrying. Do not stop unrelated Node, Godot or SteamVR processes.

## Verification

New flight checks cover flat/banked trajectories, mirrored curves, timestep
stability, bounded recall, overshoot, reflected angles and actual GLB loading.
Existing hand ownership, tuning, Bankshot, Lantern, Festival and inactive-controller
checks remain applicable. Run `scripts/check-playful.ps1` for the maintained suite;
`node scripts/check-arcade.cjs` verifies actual main-scene input, six target flights
and fresh-process persistence with disposable saves.

Public-site Playwright review at 390x844 and 1440x900 exercised bank, throw, recall,
catch, reset and model inspection with no browser warnings/errors. Screenshots are
`output/playwright/chakram-phone.png` and `chakram-desktop.png`. Actual phone GPU
performance and headset feel still need human playtesting; no VR frame-rate claim
is made from desktop/headless checks.
