# Subscription-based Claude asset commissions

Use the native Claude Code CLI with the user's signed-in Claude subscription. Never silently use API billing. Desktop and CLI sign-in are separate: a signed-in desktop does not prove that the CLI uses that account.

For every invocation, remove `ANTHROPIC_*`, `CLAUDE_CODE_USE_*`, and `CLAUDE_CODE_OAUTH_TOKEN` from the **child process environment only**. Run `claude auth status` and require the approved email, `authMethod: claude.ai`, and the expected subscription. A missing/mismatched identity is a hard stop before generation. Initial login uses `claude auth login --claudeai --email ...`. Do not extract desktop credentials. Do not use Console login, enable paid extra usage, or fall back to API credentials when subscription limits are reached.

The installed native CLI currently lives under the Claude Windows package cache, `LocalCache/Roaming/Claude/claude-code/2.1.280/claude.exe`; that version-specific path may change after updates. The CLI's own help is the source for current flags. `--model claude-opus-5-5` was accepted, and the session init reported that model with `apiKeySource: none` after subscription identity verification.

Commission artists in an isolated `work/<commission>` folder with a short creative brief and copied runtime contract. Give artistic freedom without exposing secrets or letting the worker modify the live game. Require the editable source, deterministic builder, self-contained GLB, named mechanical pivots, multi-angle renders, motion-extreme verification and a handoff. Keep the original asset until inspection and real-engine checks pass.

For this commission, `work/opus-siegebird/BRIEF.md` is the actual prompt, `run-commission.ps1` verifies subscription identity and launches Claude, and `commission.jsonl` retains the session/tool record for diagnosis. It is a private working record, never part of the public showroom. The session can be resumed for review corrections; do not rerun the initial commission blindly. Logs may contain project source, so only publish selected final assets.

Review the actual exported model in Godot as well as Blender renders. `scripts/inspect-glb.py <file> --siegebird` checks self-contained structure, required pivots, twenty rope segments and limb shape keys; it does not prove mechanical clearances. The native `--siegebird-check` exercises production gameplay. Inspect trigger/grip, crank, cables and both motion extremes visually. Report render complexity rather than assuming low-poly style is free.
