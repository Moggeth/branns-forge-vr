# Sunbeam review — 2026-10-09

Reviewed Opus-authored PR #80 against main 89f70bd in the full production map. The user screenshots show the old horizontal, over-bright shafts; PR #80 was still open. Its shorter, softer, phone-attenuated shafts remove these conspicuous bars without another render pass or simulation changes.

One correction was required: the PR normalised horizontal components independently before combining them with the vertical drop. This violated its intended minimum 62-degree downward angle as sunlight rose. Retain the original horizontal magnitude and normalise the complete vector instead. Regression coverage samples horizon through zenith, checks the actual angle and preserved compass direction, and retains weather/cloud tests.

Measured verification: focused weather suite passed; combined focused check/production build 2.320 seconds. Both draws contained 28 beams at the meadow; mobile strength changed .508 to .330. Screenshots visually confirm the long bright diagonal/horizontal stripes disappear, while the trees, grass, mountain scenery and nearby shafts remain. This is desktop emulation, not a physical phone performance claim. Initial gate-only captures (19.253 seconds) were partly obscured by the Heartstone; moving around it into the meadow provides a much more discriminating comparison.
