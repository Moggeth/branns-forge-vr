# Ground surface integration

The existing Orchard shader remains the owner of paths, terrain exposure, river wetness, rain and snow. `orchard_ground.gd` uses the authored `meadow` and `loam` maps while keeping its existing masks and bindings. `ground_surface_palette.gd` dresses the smaller zone floor patches with world-scale macro blending, near texture/normal detail, ORM roughness and the same weather inputs. Pinewood's authored ground patch and the elevated Sky Garden and Cloudbreak Keep turf surfaces receive the shared palette through selective material replacement. Starfall's ridged ground retains its imported PBR material and mesh relief.

The optional artist package lives under `godot/assets/ground-surface-kit/`:

- `materials/<family>_albedo.png`, `<family>_normal.png`, `<family>_orm.png` for `meadow`, `loam`, `stone`, `sand`, `snow`, and `ash`. Textures are seamless physical tiles at roughly 1–2 m. Normal is OpenGL +Y; ORM channels are AO, roughness, metallic.
- `props/<id>.glb` contains one merged MeshInstance3D with ground contact at local Y=0, UV/PBR materials and no collision. Godot creates import LODs.
- `manifest.json` uses schema 1: `{"schema":1,"props":[{"id":"grass_tuft","asset":"props/grass_tuft.glb","kind":"grass","zones":["orchard_highlands","sky_garden"],"weight":1.0,"scale":[0.8,1.2],"max_distance":35}]}`. Kinds are `grass`, `fern`, `litter`, `wood`, `stone`, `debris`, or `frost`. Each zone renders at most eight applicable families, selected across ecology kinds.

`GroundKit.populate` reads that manifest after its legacy dressing. It samples deterministic, seeded patch noise with open gaps. Orchard additionally uses the landscape's slope, water, ecology and mutable path/bank mask; all sites respect traversal exclusions. Props align to the terrain normal, then Orchard's existing reprojection moves them when ground height changes. Grass-like holders use the `gk_grass` naming convention so path clearing can hide them. All authored props use chunked MultiMeshes, distance culling and no per-instance physics. At normal quality the extra Orchard budget is 1,400 instances in 64 m chunks, at most eight asset families and 25 chunks per family; low/high quality scales the budget by 0.50/1.25. Small zones use one batch per family. Sky Garden and Cloudbreak Keep use their exact elevated island floor rectangles and keep 1.4 m clear at the edges and 3 m around portals. The eight-family cap chooses across ecology kinds, then favors props with fewer compatible zones, so later grass/fern entries do not disappear behind early stones.

For a quick code/material check, run the bundled Godot console executable with `--headless --xr-mode off --audio-driver Dummy --path godot --script res://ground_surface_checks.gd`. `orchard_exposure_checks.gd` verifies path-independent deformation exposure. After adding the artist package, import it with the editor, run these checks, then inspect the actual Mobile renderer in Orchard, Forge Yard, Quarry, Pinewood, and Starfall from both ground eye and tactical views. Compare visible material surfaces, draw calls and MultiMesh holder/instance counts from the same camera before accepting higher density; headless checks alone do not establish visual quality.

The small same-camera GPU check is `--xr-mode off --audio-driver Dummy --path godot --script res://ground_surface_gpu_check.gd --resolution 800x500`. It keeps its window out of focus and writes `outputs/ground-surface-check/{legacy,shared}.png`; inspect both images. With the fallback maps on the RTX 3080 Ti Mobile renderer, the legacy and shared Forge floors each used one visible object and one draw call; the run took 2.966 s. This checks shader compilation and floor draw-call parity, not the final authored maps or full-scene frame time.

After the final artist kit imports, run `--headless --xr-mode off --audio-driver Dummy --path godot --script res://ground_kit_art_checks.gd`. This strict gate requires all 18 manifest props and six material map triplets, checks imported mesh UV/normals/PBR bindings and geometry ceilings, then actually populates all 12 biomes, including elevated islands, with a seeded Orchard field. It reports per-zone instance and material-surface counts and fails for missing art; a missing kit is not an accepted result. `-- --inspect-legacy` on the same script prints imported authored ground material routing without requiring the new kit. The imported kit passed at 18 props, 12,335 source triangles, 2,290 instances and 257 holders; the first uncached check took 5.317 s and a mesh-cached rerun took 3.685 s. Orchard placement itself took 107.3 ms after the cache warmed.

Visible authored ground routing: Pinewood `zone_art/pinewood_ruins/ground_patch.glb` has one mesh `ground_patch` and one `pw_ground` surface (1,152 triangles, base+normal, no ORM); it hides the old floor, so `AuthoredZoneKit._ground_finish` replaces that surface's finish. Starfall `zone_art/starfall_ridge/ground_skin.glb` has one `ground_skin` mesh and `SF_Strata` surface (3,200 triangles, full base+normal+ORM, vertical relief to 8.435 m); retain its imported PBR material and topology. Sky Garden and Cloudbreak Keep island underside GLBs have separate `turf` surface 0 and `cliff` surface 1; the same hook duplicates the ArrayMesh and replaces only turf's material, preserving cliff strata. Gloamfen mud banks/islands and Mushroom's pond bank likewise contain several distinct water/stone/glow surfaces and need selective treatment if a real capture shows those surfaces lacking detail.

Actual Mobile-renderer review after installation: the save-isolated `environment_art_review.gd -- --world-builder-preview` captured 24 views across all 12 zones with no failures in 15.709 s shell time. The same cameras with `--ground-surface-quality=off` captured 24 baseline views with no failures in 14.981 s. Ground-level draw calls changed from 1,037 to 1,053 in Forge Yard, 336 to 358 in Pinewood, and 1,131 to 1,153 in Orchard; the tactical Orchard view changed from 1,015 to 1,026. These are global viewport draw counts, so they include the review UI and all visible scene objects. The same-camera Forge floor GPU check kept one draw call per floor with the final authored maps. Captures are in ignored `outputs/ground-surface-review-final/` and `outputs/ground-surface-review-baseline/`.
