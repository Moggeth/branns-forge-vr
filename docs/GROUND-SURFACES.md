# Ground surface integration

The existing Orchard shader remains the owner of paths, terrain exposure, river wetness, rain and snow. `orchard_ground.gd` will use the authored `meadow` and `loam` maps when they exist, while keeping its existing masks and bindings. `ground_surface_palette.gd` dresses the smaller zone floor patches with world-scale macro blending, near texture/normal detail, ORM roughness and the same weather inputs. Authored Pinewood and Starfall ground meshes already replace their hidden legacy floor visuals; keep their imported materials.

The optional artist package lives under `godot/assets/ground-surface-kit/`:

- `materials/<family>_albedo.png`, `<family>_normal.png`, `<family>_orm.png` for `meadow`, `loam`, `stone`, `sand`, `snow`, and `ash`. Textures are seamless physical tiles at roughly 1–2 m. Normal is OpenGL +Y; ORM channels are AO, roughness, metallic.
- `props/<id>.glb` contains one merged MeshInstance3D with ground contact at local Y=0, UV/PBR materials and no collision. Godot creates import LODs.
- `manifest.json` uses schema 1: `{"schema":1,"props":[{"id":"meadow_tuft","asset":"props/meadow_tuft.glb","kind":"grass","zones":["forge_yard","orchard_highlands"],"weight":1.0,"scale":[0.8,1.2],"max_distance":45}]}`. Kinds are `grass`, `fern`, `litter`, `wood`, `stone`, `debris`, or `frost`. Keep each zone to eight applicable families; excess entries are warned about and skipped.

`GroundKit.populate` reads that manifest after its legacy dressing. It samples deterministic, seeded patch noise with open gaps. Orchard additionally uses the landscape's slope, water, ecology and mutable path/bank mask; all sites respect traversal exclusions. Props align to the terrain normal, then Orchard's existing reprojection moves them when ground height changes. Grass-like holders use the `gk_grass` naming convention so path clearing can hide them. All authored props use chunked MultiMeshes, distance culling and no per-instance physics. At normal quality the extra Orchard budget is 1,400 instances in 64 m chunks, at most eight asset families and 25 chunks per family; low/high quality scales the budget by 0.50/1.25. Small zones use one batch per family. Airborne island zones have no flat-ground scatter.

For a quick code/material check, run the bundled Godot console executable with `--headless --xr-mode off --audio-driver Dummy --path godot --script res://ground_surface_checks.gd`. `orchard_exposure_checks.gd` verifies path-independent deformation exposure. After adding the artist package, import it with the editor, run these checks, then inspect the actual Mobile renderer in Orchard, Forge Yard, Quarry, Pinewood, and Starfall from both ground eye and tactical views. Compare visible material surfaces, draw calls and MultiMesh holder/instance counts from the same camera before accepting higher density; headless checks alone do not establish visual quality.

The small same-camera GPU check is `--xr-mode off --audio-driver Dummy --path godot --script res://ground_surface_gpu_check.gd --resolution 800x500`. It keeps its window out of focus and writes `outputs/ground-surface-check/{legacy,shared}.png`; inspect both images. With the fallback maps on the RTX 3080 Ti Mobile renderer, the legacy and shared Forge floors each used one visible object and one draw call; the run took 2.966 s. This checks shader compilation and floor draw-call parity, not the final authored maps or full-scene frame time.
