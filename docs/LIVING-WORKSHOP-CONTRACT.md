# Living Workshop implementation contract (20 September 2026)

This file is the coordination contract for the authorized implementation. Existing source is a native Godot game + local Node service. Do not initialize Git. Use UTF-8 explicitly. No paid generation/voice tests.

## Package v1
JSON object: schema:1; id (lowercase safe slug); version positive integer; name; kind (`item`, `region`, `rule`, `device`); scope:{kind:`instance|design|region|world`,targetId:string}; provenance:{prompt:string,interpretation:string,origin:`player|reconstructed|demo`,parentIds:string[]}; dependencies:[{id:string,version:int}]; entities:[{id:string,name:string,shape:`box|sphere|cylinder`,position:[x,y,z],size:[x,y,z],color:hex,material:`wood|iron|crystal|cloth|stone`,static:bool,components:[{type:string,config:object}]}]; links:[{id,from,to,type:`signal|energy|tether|hinge|fluid`,config:object}]; rules:[{event:string,target:string,actions:array}]; optional region:{origin:[x,y,z],spawn:[x,y,z],size:[x,y,z]}. Unknown capabilities must fail explicitly, not be silently ignored. No arbitrary eval/native script loading. Versioned interpreted rules are our supported extension route.

## Service (agent live_service owns service files)
Current authoritative limits/API are docs/LIVING-SERVICE.md and the pinned capability schema. Batch publish shares transactionId; ACK includes per-deployment generation and clientId.

`state.liveWorkshop` snapshot: {schema:1,catalog:{...},packages:[latest requested versions],history:[all versions incl provenance],deployments:{[id]:{version,status,reason}},events:[],generation:number}. GET/POST APIs `/api/vr/living/{catalog,publish,ack,rollback,history,event}` (GET catalog/history; POST others). publish accepts {package,requestId}; ack {id,version,status:`applied|deferred|rejected|staged`,reason}; rollback {id,version,requestId}; event {packageId,entityId,event,detail}. Exact versions immutable; rollback changes desired version; journal replay bounded. Ack must not fabricate readiness. Imported old ForgeStore jobs visible in history as legacy entries with original ids/modelUrl, kind `legacy`, and provenance origin reconstructed; preserve stored brief without claiming transcript fidelity. Capture conversation transcripts where feasible; no raw audio recording by default. Agent owns forge/server/world/worker integration and tests. Coordinate extra fields; no edits native.

## Native components (agent world_components owns new godot/living_components.gd + component checks)
Node class, setup(game), build(package,parent)->Dictionary {root:Node3D,entities:Dictionary,errors:Array}; construct under supplied staging parent with no live-world side effects until activate(result); deactivate(result); tick(delta); trigger(hand,target)->bool; try_grab(hand)->bool; release(hand)->bool; inspect(target)->Dictionary. Root owns native loading, per-package state, version scheduling and central entrypoint wiring. Components owns actual reusable mechanics: material properties/transformations, signals/energy/fluid links, creatures/relationships, local fields, climb/rope/hinge/portal/weakpoint, objectives, maker devices as feasible working representatives. Explicit unsupported fields/capabilities returned. No edits main.gd or existing game systems without coordinator.

## Museum / demos (agent museum owns godot/living_museum.gd, service/living-demo-packages.json, docs/LIVING-WORKSHOP-DEMOS.md)
Node setup(game), sync(snapshot), tick(delta), trigger(hand,target)->bool. Uses game.living exposed methods publish(package), rollback(id,version), history() and inspect_ray(hand). Build tasteful in-world museum/history console in a pocket hall at(-120,0,0), reached through Forge Yard gate(-11,0,1), reachable colliders and compact paginated panels with prompts/provenance and old versions. Visible ready demo buttons publish real packages; demo content follows contract, coordinate supported components directly with agent world_components. Current game can call _request via game.living facade. Includes persistent return portal and safe large grapple/climb arena as a package + representative material/signal/flow/creature/objective/maker playground. Parent owns gltf import/history metadata binding and central UI trigger wiring. Do not modify service JS or main.gd.

## Coordinator
Owns godot/living_runtime.gd, main.gd integration, hand/profile integration, package validation at native boundary, persistence state snapshots/recovery, held-version deferral, existing-item history and inspections, test harness scripts, README and final verification. No native script eval. Establish modules as installable declarative programs; newly registered engine primitives still require restart. Activation on scene boundary staged with previous package retained on error; defer held objects, preserve package state version separately. Runtime never mutates baseline nodes without recording/restoring original properties.
