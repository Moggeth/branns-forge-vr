# Structured map versus generated visual concept

`structured-seed-2000.png` is a directly registered view of the deterministic seed-2000 terrain, drainage and ecological fields. It is valid input to the 3D generator. `ai-concept.png` is a built-in image-generation **edit** of that map, prompted to preserve a broad west-to-east river across the northern Orchard, a central crossing, a hill and a valley, while suggesting stronger forest masses, bank treatment, geological silhouettes and paths. It is a visual proposal, not an elevation mask or authoritative geometry.

The generated image offers useful composition: clustered forest rather than evenly sprinkled trees, exposed bank stone, clearer path hierarchy, and a stronger difference between open meadow and wooded edges. It also redraws water more freely than the structured map, so tracing its pixels into height or river data would break deterministic hydrology, authored crossing constraints and navigation. For this first experiment the safer workflow is **structured world → generated concept → critique → hand-authored changes to splines/masks/recipes**. A future experiment can compare that against controlled feature extraction with quantitative checks, but the current game does not depend on image extraction.

Generated with the built-in image tool from the structured map; no external 3D generation or paid image API was used. The concept is retained for art direction, and the structured map remains the canonical seed-2000 evidence. The playable geological vocabulary was separately commissioned from Claude Opus 5.5 and integrated through deterministic placements.
