# Orchard Brook: shared comparison contract

This experiment is isolated from the shipped orchard. All five variants use the same 80 × 80 m Godot coordinate square, the same 23-piece orchard GLB library where applicable, identical evaluation cameras and rendering settings, and a connected path from the southwest spawn to the northeast ruin across one non-fordable stream. Layout methods may choose the stream's winding shape, exact bridge position within 8 m of the origin, terrain forms, planting and ruin arrangement. The benchmark and fixed camera definitions live in `benchmark.json` and must not change between variants.

`world_spec.json` is the authoritative, saved intermediate for each variant. Version 1 fields: `version:1`, `variant`, `method`, `seed`, `bounds_m:[80,80]`, `spawn_xz`, `goal_xz`, `path_xz` (ordered `[x,z]` vertices), `stream` (`points_xz` and `width_m`), `crossing` (`center_xz`, `width_m`, `length_m`, `yaw_rad`), `terrain` (base height plus a list of Gaussian `hills` with centre, radius and amplitude), `regions` (named polygons, surface and tree density), `objects` (asset ID, centre `[x,y,z]`, yaw, scale, interactive flag), `exclusions` (polygons or circles), and `provenance` (source image, source plan, tools, model, measured time). Machine-readable masks, source maps and diagnostic renders are saved alongside the spec. Any importer may add namespaced optional fields; it must preserve and validate the required ones.

2D map registration: pixel `(u,v)` refers to the centre of a 512 × 512 image; world `x=-40+80*(u+0.5)/512`, `z=-40+80*(v+0.5)/512`. Top of image is north, Godot `-Z`. Ground is `+Y`. The semantic palette is exact RGB before antialias correction: grass `#91ad70`, dirt path `#b98858`, water `#3f91b8`, stone/structure `#777f83`, trees `#346b3b`, clear/no-placement `#f2e8b9`, marker-spawn `#f7d54a`, marker-goal `#d060bb`, crossing `#f7f7f2`. Important anchors must use distinctive filled discs/shapes, never text alone. Height and density are separately registered greyscale images, or equivalent JSON fields derived from the same plan. A bridge is a separate structure spanning water; a single heightfield cannot encode its underside.

Ownership: the Sol planning worker owns `planning/`; the Sol Godot construction worker owns `godot/experiments/visual_2d3d/`; the Sol procedural/evaluation worker owns `variants/D/` and `evaluation/`. Opus owns isolated `work/opus-2d3d-20260928/` commission folders only. The root agent owns this contract, generated imagery, variant integration, experiments report, and all Git commits. Workers must not edit each other's files, live game code, credentials, or publishing settings.

Evaluation must distinguish image-led B from structure-led planning. A map synthesized wholly by code is not evidence of image extraction. Source imagery and cached specs are persistent; rebuilds must not require a new model call. Record attempted steps, elapsed seconds, correction deltas, render costs and unverified headset questions. No live game save or external publication is part of this experiment.
